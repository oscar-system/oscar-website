Before You Start

To avoid compatibility issues, make sure you're using OSCAR v{{ site.data.release.version }} (upgrade instructions). If you have not yet installed OSCAR, follow our installation guide.
Important: To run tutorials locally, install IJulia (Julia support for Jupyter) by completing the optional IJulia setup step from the installation guide.
---

Running Tutorials Locally

  1. Download the notebook of interest from the list below.
  2. Launch Jupyter on your machine (see Jupyter documentation).
  3. Open the downloaded notebook, and execute it using a Julia kernel.
