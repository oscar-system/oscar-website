Version 1.8.0 Released!

New features as compared to version 1.7.2 include:

  • Algebraic Geometry: Introduced DrawingCurves, a new experimental project for drawing real plane curves. Added algorithm option for ideal_membership of FreeAssociativeAlgebraIdeal. Fixed a rare Groebner basis error in quantum_symmetric_group.
  • Number Theory: Added new invariant function based on graph hash for integer lattices. Extended the use of databases of ZZLat in QuadFormAndIsom. Fixed a bug for odd lattices in automorphism group and isometry computations of quadratic lattices and tuned the heuristics.
  • Combinatorics: Added tutte_group, is_tutte_realizable, bergman_fan for matroids and on_graph for acting on a graph with a PermGroupElem. Fixed a bug and achieved a speedup in tutte_group. Added equality and hash for Graph and GraphMap, isomorphism functionality for edge-labeled graphs, and methods checking for transversals in matroids.
  • Polyhedral Geometry: Added contains and contains_in_interior for polyhedra and cones, as well as common_refinement also for polyhedral fans. Migrated slack ideals from polymake to OSCAR. Added n_rays_modulo_lineality and n_minimal_faces.
  • Commutative Algebra: Now allowing general subquotient modules as input to vector_space_dimension. Added linear solving for matrices over multivariate polynomial and Laurent rings. Introduced cohomology rings of complexes with a DG-algebra structure. Achieved a speedup of vector_space_basis for SubquoModule. Refactored existing code for ungraded modules over a MPolyLocRing localized at a point and extended its functionality to modules with true sub-part. Improved performance for vector_space_dim and vector_space_basis by using M.quo and its cached groebner_basis. Added support for sparse matrices for transformations in Groebner basis computations, and a modular algorithm for determinants of matrices over univariate polynomial rings over the integers.
  • Groups: Added maximal_supersolvable_quotient, character_table_rational, and regular_action_homomorphism for finite groups. Now allowing matrix_group(::Ring, ::Vector). Optimized stabilizer(G, v, permuted).
  • Miscellaneous: Added kostant_kumar_character and dual for roots and coroots in Lie theory. Added is_feasible(::TropicalPolyhedron) and visualize(::TropicalPolyhedron) in tropical geometry. Updated AbstractAlgebra to v0.50, GAP.jl to v0.17 and Nemo to v0.56. Changes related to serializing data in the MRDI file format.
  • For more details on the newest release, visit the GitHub Release or our website.

Papers Using OSCAR:

  • Ryan Batubara, Jack J Garzella, Yongyuan Huang, and Maximus Mellberg describe in their new preprint Newton strata realization for hypersurfaces via explicit p-adic cohomology some of the algorithms used in the DeRham.jl package and its dependencies. This package currently implements point-counting algorithms for projective hypersurfaces in Julia. Its design allows usage within the OSCAR ecosystem, especially Nemo.jl. It also supports GPU hardware for counting points via CUDA.jl. Furthermore, the paper describes some new examples of varieties that the authors found using these algorithms.
